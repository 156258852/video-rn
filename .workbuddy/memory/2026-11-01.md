- 这台机器**没有 cmdline-tools / sdkmanager**（Android Studio 装的是完整版但没有 cmdline-tools 包）。装 platform 34 走 Android Studio SDK Manager UI，或 `brew install --cask android-commandlinetools` 后命令行 `sdkmanager --sdk_root=$ANDROID_HOME "platforms;android-34"`。
